# E-RIDE

A React Native (Expo) mobile app concept for tracking e-bike/e-scooter rides.

## Overview
E-RIDE is a rider-facing app prototype with a bottom tab navigation structure for starting rides and reviewing past ride history.

## Features
- Ride screen for starting/tracking a current ride
- Ride history screen for past trips
- Custom font loading and app icon/splash assets

## Tech
- **Framework:** React Native + Expo
- **Navigation:** Bottom tab navigator
- **Language:** JavaScript

## Structure
- `App.js` — app entry point, font loading
- `BottomTabNavigator.js` — tab navigation setup
- `Ride.js` — active ride screen
- `RideHistory.js` — past rides screen

## Status
Prototype / concept app — not published to app stores.
